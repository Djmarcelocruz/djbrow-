# O Pacto de Prazer — Edição Pro

Jogo interativo de desafios desenvolvido com tecnologias web modernas. Esta aplicação funciona como um SPA (Single Page Application) e foi desenhada para ser responsiva e funcionar offline.

## 🚀 Funcionalidades
- **Roda da Fortuna:** Sistema de sorteio dinâmico com física de rotação.
- **Editor de Desafios:** Personalização total das tarefas diretamente pela interface.
- **Modo PWA:** Suporte para funcionamento offline e instalação em dispositivos móveis.
- **Exportação/Importação:** Backup de dados em formato JSON.
- **Segurança:** Sistema de bloqueio por senha para proteção de conteúdo.

## 🛠️ Tecnologias Utilizadas
- HTML5 & CSS3 (Variáveis CSS, Grid, Flexbox)
- JavaScript Nativo (ES6+)
- IndexedDB para armazenamento persistente no navegador.

## ⚙️ Como Executar
Basta abrir o ficheiro `index.html` em qualquer navegador moderno ou aceder através do link do GitHub Pages.
